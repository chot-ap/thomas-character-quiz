# きかんしゃトーマス キャラクターあてクイズ 🚂

きかんしゃトーマスの人気キャラクターをあてるWebクイズゲームです。

👉 **[Webアプリをあそぶ（公開ページ）](https://chot-ap.github.io/thomas-character-quiz/)**

---

## 🌟 アプリの特徴
- **全10問**：トーマス、パーシー、ジェームス、ゴードン、ヘンリー、エドワード、トビー、エミリー、ヒロ、ディーゼル
- **10秒シンキングタイム**：画像を見てだれか当てよう！4択タップでも声に出してもOK！
- **正解発表（3秒）**：10秒後にキャラクターの名前と特徴が大きく表示されます（音声読み上げ付き）
- **自動遷移**：3秒後に自動的にテンポよく次の問題へ進行
- **サウンド演出**：汽笛、チクタクカウント、ピンポン正解チャイム、ファンファーレ（Web Audio API）

## 🎮 遊び方
スマートフォン、タブレット、PCのブラウザから上記URLを開くだけですぐに遊べます！
